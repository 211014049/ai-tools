Runway 是什么？

Runway 是 AI 视频生成领域的头部平台，旗下 Gen 系列模型可以通过文字或图片生成高质量动态视频，支持镜头控制、运动笔刷、首尾帧过渡等专业能力，被用于短片、广告与电影预演制作。

除生成外，Runway 还内置绿幕抠像、物体擦除、慢动作、口型同步等 30+ AI 魔法工具，覆盖从生成到后期的大部分环节，是内容创作者和影视团队的一站式视频工作台。

核心功能特点

  • Gen 系列文生视频 / 图生视频
  • 运动笔刷与镜头方向控制
  • 绿幕抠像、物体擦除等 AI 后期工具
  • 首尾帧精准过渡
  • Web 端在线协作
  • API 供开发者集成
